1. For the start of this road map I have decided to begin learning embedded programming using an STM32C031C6 NUCLEO development board.
I want to focus initially on simple bare metal applications. An appropriate starting place would be turning on an LED.

2. The next task I want to do in bare metal is to blink an LED. Rather than simply using a software loop I think it would be much more meaningful to approach this with the mindset of an electrical engineer. So I have decided to implement a PWM output signal using the STM32C02C6 built in hardware timers.
